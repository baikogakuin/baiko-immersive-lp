# 今日は、梅光生。

実際の学校写真を使った、一日の生活を想像するための体験LP。
写真上の行き先、視点の移動、拡大縮小、過ごし方の選択で学校を巡ります。
一日の最後は、オンライン説明会 → 入試説明会（来校）→ 来校後に家族と振り返る、へつながります。

場面の順序は実際の時間割ではなく、音は試作の合成音です。
GitHub Pagesで公開する静的サイトです。HTML・CSS・JavaScriptとWeb用写真のみを収録しています。

## 説明会の日時・申込URLを入れる
`config.js` の `date` と `url` を書き換えるだけで反映されます。空欄のあいだは「未確定」と表示し、学校サイトの最新案内へリンクします。

## 来校後の振り返り
`?recap` を付けたURL（例：`https://baikogakuin.github.io/baiko-immersive-lp/?recap`）を開くと、振り返りの場面から始まります。配布物のQRに使えます。

## オープニングと説明会への導線
22秒のオープニング、明朝体テロップ、場面ごとの写真の色調補正を追加。右下のオンライン説明会ボタンは、冒頭と青春ムービーの再生中も利用できます。
